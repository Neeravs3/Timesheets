Timesheets

Timesheets is a personal automation tool that generates monthly PDF reports and creates email drafts in Gmail.

Purpose of the Application

This application is designed to automate a repetitive monthly workflow for its owner. It reads local data, generates a formatted PDF summary, and uses the Gmail API to create a draft email with the PDF attached. This allows the owner to review the report before sending it to recipients.

Data Usage

The Gmail API scope gmail.compose is requested solely to create email drafts on behalf of the account owner. The application does not read, store, or share any email content or personal data belonging to any third party.

Access

This is a personal tool intended for use only by its owner. It is not available for public registration or use.
